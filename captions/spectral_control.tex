Closed-loop spectral control using the ERA+EM $n_x=4$ model ($n_x = 4$), controller hyperparameters tuned by random search (8 trials each). The target is a sum of two sinusoids at $f \in \{0.01, 0.03\}$ cycles per sample with amplitudes $A \in \{1.50, 1.50\}$, centred on a physical mean of 4. Each column shows one controller (LQG, LQI, MPC) with a per-neuron tracking cost ($\lambda_{\mathrm{var}} = 1$). Row 1: physical population mean $\overline{y}(t)$, uncontrolled baseline (grey dashed), and target reference (black dashed). Row 2: per-neuron observations $y(t)$ as a neuron $\times$ time heatmap. Row 3: applied inputs $u(t)$.
